# DESIGN.md — Giftia デザインの方針

班員と AI が画面を作るときに守るデザインのルールです。
迷ったら「いまの画面に溶け込むか」を基準にしてください。

## 1. 基本のルール

1. **いまの色はすべてそのまま使う。** 基本の色（`frontend/app/globals.css`）もカテゴリーの色（`frontend/public/placeholders/*.svg`）も変えない
2. **いまのコンポーネントの見た目は変えない。** ボタン・入力欄・カード・モード切替の形と色は、いまの `globals.css` のまま使う
3. 新しい部品を作るときも、2章・3章の色の中から選ぶ。新しい色は足さない
4. どうしても色を変える・足す必要が出たら、班で相談して決め、先にこのファイルを書き直してから実装する

## 2. いまのデザインの考え方

いまの画面は「静かで、読みやすく、商品と推薦理由が主役」になるように作られています。

| 考え方 | いまの画面での現れ方 |
|---|---|
| 色数を絞る | 使う色はほぼ文字色・補助文字色・線・紺のアクセントの4つだけ |
| 白と生成りで面を作る | 背景は真っ白ではなく、少し温かい `#fafaf9`。カードだけを白（`#fff`）にして浮かせる |
| 強調は紺の1色だけ | 見出し・押せるボタン・選択中のモード・推薦理由の左線が同じ紺（`--accent`） |
| 線は細く薄く | 枠線は `1px` の薄いグレー（`--line`）。影は使わない |
| 角は少しだけ丸く | 入力欄・ボタン `6px`、カード `8px`。モード切替だけ丸いピル型（`999px`） |
| 推薦理由を目立たせる | 理由（`.reason`）は薄い青の面＋紺の左線。カードの中で一番目に入る場所にする |
| 装飾より情報 | アイコン・グラデーション・影・アニメーションは使わない |

### 色のトークン（`globals.css` の `:root`）

| トークン | 値 | 用途 |
|---|---|---|
| `--ink` | `#1f2933` | 本文の文字 |
| `--sub` | `#616e7c` | 補助情報（順位・ブランド・評価・件数） |
| `--line` | `#e4e7eb` | 枠線 |
| `--accent` | `#1b3a5c` | 紺。見出し・主ボタン・選択中・推薦理由の線 |
| `--bg` | `#fafaf9` | ページの背景 |
| `--warn` | `#b42318` | エラー文 |
| （直書き） | `#fff` | カード・入力欄の面 |
| （直書き） | `#eef2f7` | 推薦理由の面 |

### 文字

- 書体：`"Hiragino Sans", "Yu Gothic", "Meiryo", sans-serif`（端末の日本語ゴシック）
- サイズ：ページ見出し `24px` / 商品名 `16px` / 入力・ボタン `15px` / 本文・理由 `14px` / 補助 `13px`
- 太字は価格だけ。見出し以外で太字を増やさない

### レイアウト

- 本文の最大幅 `960px`、左右の余白 `16px`
- 余白は `4 / 8 / 12 / 16px` の刻みで取る
- カードは「左に画像 120px・右に情報」。幅 `560px` 以下では縦に積み、画像は横いっぱい・高さ `120px`

## 3. カテゴリーの色

カテゴリーの色は、いまの仮画像（`frontend/public/placeholders/*.svg`）の色をそのまま使う。
どれも「薄い面の色」と「濃い線・文字の色」の2色1組で、彩度を抑えた落ち着いた色になっている。

| カテゴリー | 仮画像 | 面の色 | 線・文字の色 | 色味 |
|---|---|---|---|---|
| 食品 | `food.svg` | `#f3e3c3` | `#8a5a1f` | 茶 |
| 飲料 | `drink.svg` | `#d9ecf2` | `#1f5f73` | 青緑 |
| 酒類 | `alcohol.svg` | `#eadcf0` | `#5b2a73` | 紫 |
| 生活雑貨 | `goods.svg` | `#e3ecdf` | `#3d6634` | 緑 |
| インテリア | `interior.svg` | `#efe6dc` | `#6b4a2b` | 木の茶 |
| コスメ | `cosme.svg` | `#f6e1e6` | `#8a2f4a` | ローズ |
| 家電 | `appliance.svg` | `#e1e6ee` | `#2f3f5a` | 青灰 |
| ビジネス小物 | `business.svg` | `#e6e6e6` | `#3a3a3a` | グレー |
| フラワー | `flower.svg` | `#fbe7ea` | `#a0364f` | ピンク |
| カタログギフト | `catalog.svg` | `#f0eddc` | `#6a5d1f` | オリーブ |

- カテゴリー名と仮画像の対応は `frontend/lib/api.ts` の `SLUG` にある。表にないカテゴリーは生活雑貨（`goods.svg`）の画像になる
- 新しいカテゴリーを足すときは、既存の色と並べて浮かない色を2色1組で決め、この表に書いてから使う

## 4. カテゴリー色を使ってよい場所・いけない場所

| 使ってよい | 使わない |
|---|---|
| 商品の仮画像（背景・線・文字） | ボタン・選択中のモードなど、押せるもの（紺のまま） |
| カテゴリーを示す小さな目印（タグなど）を付ける場合 | ページの背景・見出し |
| | 推薦理由の面と線（紺系のまま。理由はカテゴリーに関係なく同じ見た目にする） |
| | エラーや注意の表示 |

理由：押せるものの色がカテゴリーごとに変わると、どこが操作できるのかが分からなくなるため。

## 5. 新しく画面や部品を作るとき

- 色は `globals.css` のトークン（`var(--accent)` など）を使い、新しい色を直書きしない
- 文字と背景の明るさの差（コントラスト比）は 4.5 以上にする
- 影・グラデーション・アニメーションは足さない。必要なら班で相談してからこのファイルに書き足す
